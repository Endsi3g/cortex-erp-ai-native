# Cortex Acceptance Tests

Scénarios d'acceptation comportementaux (Behavior-Driven Development / Gherkin) décrivant les critères d'acceptation de Cortex ERP.

## 📂 Scénarios Disponibles

- `features/quote_draft_creation.feature` : Création de devis par un agent Onyx sans réservation d'inventaire.
- `features/consignment_split.feature` : Calcul des commissions de consignation par numéro de série.
- `features/availability_check.feature` : Précision du calendrier de disponibilité.
