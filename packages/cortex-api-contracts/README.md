# Cortex API Contracts

Ce package regroupe les spécifications OpenAPI 3.1 définissant les contrats de données d'interface pour Cortex ERP.

## 📂 Spécifications

- `openapi/openapi-onyx-agent.yaml` : Contrat restreint et typé dédié aux agents Onyx et au serveur MCP.
- `openapi/openapi-public.yaml` : Contrat pour intégrations tierces et partenaires.
